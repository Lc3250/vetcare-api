# ЗАВДАННЯ

## Застосунок
**VetCare API** – навчальний REST-сервіс для обліку пацієнтів ветеринарної клініки: власники, тварини, візити та вакцинації з контролем термінів ревакцинації.
Цільові користувачі: адміністратор і лікар невеликої ветклініки.

Функціональні вимоги:
1. Реєстрація та редагування власників.
2. Реєстрація тварин (вид, кличка, дата народження, власник).
3. Облік візитів (дата, причина, діагноз, нотатки).
4. Облік вакцинацій (вакцина, дата, серія).
5. Автоматичний розрахунок дати наступної ревакцинації за довідником вакцин.
6. Список тварин із простроченою ревакцинацією.
7. Пошук тварин за кличкою, видом чи власником.
8. Експорт історії тварини у JSON.

Технологічний стек: Python 3.12, FastAPI, SQLite, pytest, ruff.
Докладно: [docs/app-requirements.md](docs/app-requirements.md).

## Обрана агентна IDE
**Claude Code.** Підтримує MCP-сервери, виконання bash-команд, проєктні інструкції (`CLAUDE.md`), hooks (pre-/post-tool-use), skills і subagents – тобто все, що потрібно для ПР3–ПР6.

## Мета harness
Прискорити й убезпечити розробку VetCare API: давати агенту знання про застосунок через окрему базу знань (vault), формалізувати типові процедури (тести, рев'ю, ADR) та обмежити небезпечні автономні дії.
Докладно: [docs/harness-requirements.md](docs/harness-requirements.md).

## Цільові задачі агента
1. Генерація каркасу нових модулів за прийнятою архітектурою.
2. Генерація unit- та інтеграційних тестів.
3. Рев'ю коду за конвенціями проєкту.
4. Підтримка документації та нотаток бази знань у синхронізації з кодом.
