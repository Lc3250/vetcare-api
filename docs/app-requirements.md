# Вимоги до застосунку VetCare API

## Опис і користувачі
Невеликий REST-сервіс для ветеринарної клініки. Він зберігає дані про власників, тварин, візити та вакцинації й підказує, кому з пацієнтів пора на ревакцинацію. Користувачі: адміністратор (реєструє власників і тварин) та лікар (вносить візити й щеплення).

## Предметна область і межі
Лише облік і нагадування. Поза межами: оплата, склад препаратів, розклад лікарів, автентифікація користувачів. Реальних персональних даних немає, лише тестові.

## Функціональні вимоги
| № | Вимога |
|---|--------|
| ФВ-1 | Створення, перегляд і редагування власників |
| ФВ-2 | Реєстрація тварин із прив'язкою до власника |
| ФВ-3 | Облік візитів тварини з діагнозом і нотатками |
| ФВ-4 | Облік вакцинацій (вакцина, дата, серія) |
| ФВ-5 | Розрахунок дати наступної ревакцинації за довідником вакцин |
| ФВ-6 | Список тварин із простроченою ревакцинацією |
| ФВ-7 | Пошук тварин за кличкою, видом, власником |
| ФВ-8 | Експорт повної історії тварини у JSON |

## Нефункціональні вимоги
- Продуктивність: відповідь API до 200 мс на типових запитах при базі до 10 000 записів.
- Безпека: валідація всіх вхідних даних, параметризовані SQL-запити, відсутність секретів у репозиторії.
- Якість: покриття тестами не менше 80 %, перевірка стилю через ruff.
- Супровідність: чіткий поділ на шари `api/`, `core/`, `storage/`.

## Технологічний стек
Python 3.12, FastAPI, SQLite (вбудована БД, без окремого сервера), pytest, ruff, git/GitHub.

## Вибір агентної IDE
Обрано **Claude Code**. Відповідність критеріям: MCP-сервери підтримуються (потрібно для конектора в ПР3), bash у робочій директорії є (git), проєктні інструкції задаються через `CLAUDE.md`, механізм hooks є (guardrails у ПР4). Вибір не змінюватиметься до кінця курсу.

## Оцінка вибору застосунку
Обмежена область, понад 8 функцій, які можна нарощувати за 7 робіт без переписування архітектури; безкоштовний стек; правильність перевіряється автоматичними тестами (наприклад, дата ревакцинації); немає реальних користувачів і production-даних, тож ризик автономних дій низький.
