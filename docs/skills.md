# Skills (ПР5)

Skills лежать у `.claude/skills/<назва>/SKILL.md` і викликаються Claude Code за описом або за іменем.

| Skill | Задача з ПР1 | Що використовує з harness |
|-------|--------------|----------------------------|
| `gen-unit-tests` | генерація тестів | vault через `search_notes`/`get_note` (правила предметної області), guardrails W-01, W-03, B-01, B-02, B-06 |
| `write-adr` | синхронізація знань | `search_notes` (дублікати, номер), `get_note`, `ingest_note`, `link_notes`; guardrails W-05, B-02, B-06 |

Обидва skills описують призначення, покрокову процедуру, посилання на guardrails і формат результату.

## Результати застосування

Усі прогони виконано в одній сесії Claude Code (хмарне середовище) за кроками SKILL.md. Виклики vault ішли через MCP-клієнт `scripts/mcp_call.py` (протокол stdio), а не через вбудовану підсистему MCP цієї сесії.

### gen-unit-tests: 3 реальні задачі
| Задача | Модуль | Тести | Результат |
|--------|--------|-------|-----------|
| 1 | `core/vaccination_schedule.py` | 7 | пройшли з першого запуску; правило «інтервал у днях» взято з ADR-003, що виявило граничний випадок 29.02 |
| 2 | `core/overdue.py` | 7 | пройшли з першого запуску; строгість порівняння (`due < today`) зафіксовано окремим тестом і ADR-008 |
| 3 | `storage/repository.py` | 5 | **тест виявив дефект**: `LIKE` не ігнорує регістр для кирилиці, пошук «барс» не знаходив «Барсик». Виправлено (SQL-функція `py_fold`, екранування `%` і `_`), додано тест на wildcard; рішення зафіксовано в ADR-009 |

Підсумок: 55 тестів у наборі (разом із ПР3–ПР4), `ruff` без зауважень.

### write-adr: 3 реальні задачі
| ADR | Створено | Зв'язки | Повторний виклик |
|-----|----------|---------|------------------|
| ADR-007 Довідник вакцин як словник у core | created | Модуль графіка ревакцинації implements | unchanged |
| ADR-008 Прострочення за строгим порівнянням дат | created | Модуль прострочених вакцинацій implements | перевірено лише для ADR-007 |
| ADR-009 Дати як ISO-текст і пошук без регістру в SQLite | created | Репозиторій SQLite implements | перевірено лише для ADR-007 |

Після записів `check_vault.py`: 28 нотаток, усі досяжні з MOC, зв'язки відповідають онтології.

## Де знадобилось ручне втручання
1. **Дефект коду, знайдений тестом** (задача 3): skill за процедурою не змінює код без запиту, тому знахідку зафіксовано й виправлено окремим кроком людини/розробника.
2. **Обмеження пошуку в vault.** `search_notes` шукає точний підрядок: запит «ревакцинації» знайшов нотатки з цією формою слова, але запит у формі «ревакцинація» пропустив би частину. Для skills це означає, що ключові слова доводиться підбирати вручну. Це мотивація для ПР7.
3. **Підтвердження за guardrails.** Правила W-01, W-03, W-05 вимагають підтвердження людини. У цьому прогоні hook не був активним у сесії, тому запити на підтвердження не виникали; поведінку hook перевірено окремо тестами ПР4.
4. **Дрібна помилка в тексті ADR-008** (русизм «льготний») виправлена вручну після запису.
